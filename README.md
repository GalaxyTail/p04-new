## Описание проекта
Учебный проект — адаптивная страница со списком синтетических заказов и формой поиска. 
Реализована с использованием Bootstrap 5.3 (локальная версия) и чистого JavaScript.

## Структура
- `index.html` - разметка страницы.
- `styles.css` - кастомные стили (фокус, перенос слов).
- `app.js` - логика (функции `normalizeOrderCode`, `lineTotal` и рендер карточек).
- `css/`, `js/` - локальный Bootstrap 5.3.
- `report.md` - полный отчет по тестированию.

## Как запустить
Открыть файл `index.html` в любом современном браузере (двойным кликом). Внешний сервер не требуется.
